 👩🏻‍🎓🧑🏻‍🎓Student-Performance-Management-System(SPMS)
A Programming Fundamentals project for managing student performance using C++.
A console-based C++ application that helps students and teachers store, analyze and track grades  while generating reports on academic performance.
It manages student records using a menu-driven interface.
🔧Features:
Add, update, delete, and search student records  
Manage marks for quizzes, assignments, midterms and final exam  
Calculate total marks, percentage, and grades  
Display class topper(s), averages, and highest/lowest scores  
Sort students by percentage  
Save and load data using files  
Export student report to a text file  
🛠️Technologies used:
 C++
Standard libraries: `iostream`, `fstream`, `string`, `iomanip`
--Concepts Used
Structures (`struct Student`) to store student data  
1D & 2D arrays for marks management  
Functions for modular and reusable code  
File handling using `ifstream` and `ofstream`  
Input validation (marks range, names, menu choices)  
 Menu-driven program using loops and conditionals  
Version control with GitHub
